# Automações em Python para Excel

Pequenos scripts úteis para quem trabalha com planilhas.

## Como usar

1. Clone o repositório
2. Instale as dependências: `pip install -r requirements.txt`
3. Coloque seus arquivos Excel na pasta `dados/entrada/`
4. Execute o script desejado, ex: `python 01_unir_planilhas.py`

## Scripts disponíveis

- `01_unir_planilhas.py` – junta vários Excels em um único arquivo.
- `02_extrair_filtro.py` – filtra linhas por um valor mínimo em uma coluna.
- `03_gerar_grafico.py` – cria gráfico de barras automaticamente.
- `04_formatar_relatorio.py` – aplica formatação profissional (cores, bordas).
- `05_validar_dados.py` – valida CPF, e-mail e valores negativos.

Cada script pode ser adaptado para seu próprio cenário.
